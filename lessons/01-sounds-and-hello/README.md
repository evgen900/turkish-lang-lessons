# Буквы, звуки и первое знакомство

Статус: материал подготовлен; учеником не пройден.

Откройте `index.html` в браузере. Это самостоятельный файл со встроенными аудио и SVG. `speaking.md` — инструкция отдельному голосовому агенту, также есть целиком в HTML. `cards.tsv` — исходник карточек UTF-8, не автоматический планировщик.

MP3 и точные тексты в `audio/manifest.json`; синтез Microsoft Edge TTS, дата 2026-11-03, слуховая проверка носителем не выполнялась. Для изменения контента правьте `tools/build_lessons.py` в корне, пересоздавайте изменённые MP3 через `tools/generate_audio.py`, затем собирайте HTML.
