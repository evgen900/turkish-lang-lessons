# Инструкции для будущих агентов

## Задача репозитория

Личный курс турецкого с абсолютного нуля до практического A2 для русскоязычного ученика. После устойчивого A2 пересмотреть стратегию для B1. Это учебные материалы и журнал, а не программный продукт, который нужно бесконечно усложнять.

Перед работой прочитать `docs/LEARNER.md`, `docs/STRATEGY.md`, `docs/ROADMAP.md`, `progress/LOG.md` и `docs/LESSON_STANDARD.md`. Для разговорного занятия дополнительно `agents/SPEAKING_COACH.md` и сценарий нужного урока.

## Обязательные требования пользователя

- Теория каждого урока — HTML, удобный для чтения с телефона.
- **Каждый отдельный урок — отдельная папка** `lessons/NN-slug/`, основной файл `index.html`.
- В каждом уроке теория, практика, обязательное говорение с отдельным агентом, аудио с точным текстом и упражнение на связь звук ↔ написание.
- Добавлять картинки и схемы, когда это помогает обучению; объяснять их текстом. Не вставлять декорации вместо практики.
- Начинать с алфавита, звуков и чисел. Не предполагать никаких прежних знаний турецкого.
- Стратегия и roadmap изменяются по данным прогресса. Скорость важна, но нельзя выдавать знакомство с правилом за навык.
- Публикация через content-publisher — по отдельному запросу. Сам факт создания урока не разрешает публикацию.

## Педагогика и честность

Объяснять по-русски, примеры давать на турецком с `lang="tr"`. Вводить маленькую активную порцию (обычно 5–8 слов/выражений); справочник явно отделять от обязательного запоминания. Алфавит и ряд чисел — исключения, их можно разбивать на несколько подходов. Сохранять ı/i, İ/I, ç/ş/ö/ü/ğ. Русская транскрипция только временная приблизительная подсказка, никогда не основной текст.

Не объявлять универсальную формулу «A2 за N дней». Отличать исследовательский результат от нашего решения. При обновлении методики искать первоисточники, указывать дату поиска, ограничения и область переноса на турецкий. Не придумывать DOI, исследования и аудио носителей.

Синтезированную речь маркировать, хранить текст, голос, дату и статус проверки. Она не заменяет разнообразие живых голосов. Текстовый чат не позволяет оценивать произношение; распознанный текст не является доказательством правильных звуков. При отсутствии аудиовхода фиксировать «произношение не оценено».

Не отмечать урок пройденным и не менять профиль/результаты по догадке. Записывать только реальные ответы и самоотчёт с указанием источника. Предложенный тест не равен пройденному тесту. Обновлять план после контроля, сохраняя предыдущую логику изменений в `progress/DECISIONS.md`.

## Выпуск урока

Следовать `docs/LESSON_STANDARD.md`. Дать ответы под раскрываемыми блоками, варианты для усталого дня, возврат через 1/3/7/14 дней, критерии завершения и сценарий для голосового агента. Проверить смысл турецких фраз и соответствие аудио тексту. До заявления о готовности проверить ссылки, мобильную ширину, воспроизведение и режим без сети; сообщить, если слуховая проверка носителем не выполнялась.

Не создавать следующие десятки уроков автоматически: сначала учитывать реальные трудности ученика. Пользовательские файлы и `.vscode/` не трогать без необходимости. Не коммитить и не публиковать без запроса. При изменении готовых HTML править источник `tools/build_lessons.py`, затем пересобирать.
