# Турецкий с нуля → A2

Личный, пересматриваемый курс для русскоязычного начинающего. Версия 1.0 от 3 ноября 2026 года. Цель — справляться с повседневными ситуациями на турецком, затем отдельно спланировать B1.

## Начать

Откройте [каталог курса](index.html) в браузере или сразу:

1. [Урок 01: буквы, звуки и первое знакомство](lessons/01-sounds-and-hello/index.html).
2. [Урок 02: числа 0–10 и вежливая просьба](lessons/02-numbers-and-requests/index.html).

Каждый урок находится в отдельной папке. HTML рассчитан на телефон; озвучка и иллюстрации встроены. Можно переслать себе файл `index.html` из папки урока и открыть его браузером. Если приложение телефона показывает только предпросмотр, скачайте файл и откройте в полноценном браузере. Аудио запускается по нажатию. Интернет для самих уроков не нужен. На телефоне удобнее также открыть позже опубликованную ссылку.

Начните с 10 минут первого урока: послушайте гласные, повторите и скажите `Merhaba`. Не нужно за один раз запоминать весь справочник алфавита.

## Рабочий темп

Пока график не подтверждён: 30–45 минут, 6 дней в неделю, включая разговорную практику. Плановый бюджет до A2 — **180–260 часов осмысленной работы**, это наша гипотеза для планирования, а не норма CEFR или гарантия. При таком режиме это примерно 9–20 месяцев; менять оценку после первых 10 часов и каждой контрольной точки. Движение определяют выполненные задачи, а не количество открытых страниц.

## Публикация и обслуживание

Сейчас материалы только локальные: ничего не опубликовано. По отдельной просьбе ученика можно передать `lessons/NN-.../index.html` в content-publisher. Встроенные аудио, CSS и SVG позволяют публиковать один файл; соседние уроки могут требовать отдельной публикации. При публикации всего курса сохранять дерево папок.

Техническое воспроизведение: `python -m pip install -r requirements-tools.txt`, затем `python tools/build_lessons.py`. Готовые HTML не требуют Python. Источник содержания и оформления уроков — этот генератор, тексты аудио — `audio/manifest.json` внутри каждой папки. Аудио уже сохранено; `python tools/generate_audio.py` нужно только при изменении записей (требует сети). Проверка: `python tools/verify.py`.
