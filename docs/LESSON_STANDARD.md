# Стандарт урока и выпуск HTML

## Структура

```
lessons/NN-topic/
  index.html          # самостоятельный мобильный урок, теория и практика
  README.md           # цели, статус и способ повторной сборки
  speaking.md         # сценарий отдельному разговорному агенту
  cards.tsv           # UTF-8: id, prompt_ru, answer_tr, audio_id
  audio/
    manifest.json     # id, text, voice, file, kind; точная расшифровка
    *.mp3
```

Полезные картинки/схемы хранить рядом либо встраивать SVG в HTML. Встроенные SVG первых уроков — авторские учебные схемы, не фотографии артикуляции. Для чужих материалов записывать URL и условия использования; найденное в интернете не означает разрешённое к копированию. Не нужна иллюстрация — не добавлять ради числа картинок.

## Педагогический минимум

- Известные предпосылки, результат «могу…», время, вариант на 10 минут.
- Одно маленькое новое правило, небольшой активный словарь. Переводы не спрятаны настолько, что новичок не понимает задачу.
- Точный турецкий текст каждого образца и явный режим «сначала послушай, затем открой» хотя бы для диктанта/проверки.
- Звук → буква/слово и текст → произнесение. Прослушать аудио недостаточно: нужен ответ ученика.
- Осмысленная речь с отдельным агентом: задача, ограничения лексики, процедура помощи, критерии успеха.
- Ответы и объяснение типичных ошибок в `details`, самопроверка без взгляда на ответ, домашнее задание и повтор через сутки/3/7/14/30 дней.
- Порог завершения не равен сертификации A1/A2. Писать «готов к следующему шагу», не «теперь знаешь весь алфавит» после одного просмотра.

## Телефон и доступность

`lang="ru"`, UTF-8, viewport, основной текст ≥18 px, ограниченная ширина строки, кнопки ≥44 px, перенос длинных строк, отсутствие горизонтального скролла на 360–430 px. Турецкие фрагменты с `lang="tr"`. Видимый фокус, достаточный контраст; цвет не единственный носитель информации. Текстовые подписи у иллюстраций. Никакого autoplay, внешних шрифтов и CDN. Нативные `<audio controls>` и понятная подпись. Работает без JavaScript: текст, раскрытие ответов и аудио доступны. JS только для удобства (скорость, копирование).

Встроенный TTS аудиофайл — основной вариант, браузерный speechSynthesis не должен быть единственным источником. Голос на устройстве может отсутствовать. Синтетика явно подписана; не утверждать, что её проверил носитель. У исходных MP3 известны текст, движок/голос и дата генерации. При изменении текста обновить MP3 и HTML вместе.

## Публикация

По отдельному запросу прочитать актуальный skill content-publisher и выполнить его инструкции. Для отдельного урока передавать его `index.html` с встроенными ресурсами. Не использовать локальные Markdown-ссылки как необходимую часть упражнения. В HTML полный сценарий для агента доступен без соседнего файла. Кнопка «скопировать» имеет резервный путь: выделить текст вручную. Ссылки между уроками могут не работать при публикации одной страницы; прямо указывать это внизу.

## Контроль выпуска

`python tools/verify.py`: структура, ссылки, manifest/HTML, audio decode. В браузере проверить 360, 390, 430 и desktop: отсутствие overflow, раскрытие ответов, аудио/скорость/копирование, отсутствие сетевых зависимостей. После переноса отдельного HTML в другую папку проверить снова. Ручное прослушивание человеком/носителем — отдельный статус; автоматическая декодируемость его не заменяет. До публикации по возможности прослушать сомнительные элементы и получить фонетическую проверку.
